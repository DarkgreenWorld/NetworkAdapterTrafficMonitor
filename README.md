# NetworkAdapterTrafficMonitor

Monitor the traffic of specific network adapters on your Windows

Author: Gemini 3.0 Pro Preview, Darkgreen World

latest release version: 1.0.1

You can use this program to monitor the traffic of any network adapter on your Windows. If your computer has [Npcap](https://github.com/nmap/npcap) installed, you can also monitor the traffic of specific connection IP on the adapter and issue warnings when traffic is generated by that IP.
